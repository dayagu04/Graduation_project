36|Normal|
37|Normal|
38|Normal|随着我国高等教育规模的持续扩大与教育信息化的普及，高校教务系统积累了海量的学生数据。然而，传统的教学评价体系长期依赖于单一的期末分数进行总结性评价，难以深度挖掘学生学业表现背后的复杂行为动因，导致个性化教学难以有效开展。为打破唯分数论的评价局限，本研究将教育数据挖掘技术引入学业评价体系，提出了一种基于粒子群优化与 K-Means 融合（PSO-KMeans）的改进聚类分析模型。
39|Normal|首先，本研究对包含 14,003 条多维样本的异构教育数据集进行了深度清洗与 Min-Max 无量纲化处理。结合教育学先验理论，创新性地构建了学业综合得分与学习效率等衍生特征，将分析视角从静态成绩向动态行为模式平移。其次，针对传统 K-Means 算法在高维非凸空间中极易陷入局部最优解的缺陷，本研究引入了 PSO 算法的全局启发式搜索机制。实验结果表明，在通过肘部法与轮廓系数确定最佳聚类簇数（）的前提下，PSO-KMeans 算法有效克服了传统算法的波动性，其聚类误差平方和的均值与标准差均达到优水平，实现了较优的收敛稳定性。
40|Normal|最后，本研究将优化后的模型投入业务应用，成功解译出四类具有鲜明行为特征的学生群体。通过多维质心偏离度分析发现，驱动学生分群的核心要素并非绝对分数，而是精力分配与数字技术使用偏好。基于群体画像，本文提出了针对性的学业诊断与教学干预策略，构建了从底层算法寻优到顶层教务管理的完整闭环。本研究不仅为高校实施因材施教提供了量化的数据支撑，也为大数据驱动下的教育教学改革提供了可靠的技术范式。

44|Normal|ABSTRACT
45|Normal|
46|Normal|
47|Normal|With the continuous expansion of higher education and the popularization of educational informatization, massive amounts of student data have been accumulated in university academic systems. However, traditional teaching evaluation systems have long relied on a single final score for summative assessment, making it difficult to deeply mine the complex behavioral motivations behind students' academic performance, thereby hindering the effective implementation of personalized teaching. To break the limitations of score-centric evaluation, this study introduces Educational Data Miningtechnologies into the academic assessment system and proposes an improved clustering analysis model based on the fusion of Particle Swarm Optimization and K-Means (PSO-KMeans).
48|Normal|Firstly, this study conducted deep cleaning and Min-Max dimensionless processing on a heterogeneous educational dataset containing 14,003 multi-dimensional samples. Guided by pedagogical prior theories, derived features such as Academic Composite Score and Study Efficiency were innovatively constructed, shifting the analytical perspective from static scores to dynamic behavioral patterns. Secondly, addressing the inherent defect of the traditional K-Means algorithm, which is highly susceptible to local optima in high-dimensional non-convex spaces, this study introduced the global heuristic search mechanism of the PSO algorithm. Experimental results demonstrate that, after determining the optimal number of clusters (K=4) via the Elbow Method and Silhouette Coefficient, the PSO-KMeans algorithm effectively overcame the volatility of traditional algorithms. Its mean and standard deviation of the Sum of Squared Errors (SSE) reached optimal levels, achieving exceptional convergence stability.
49|Normal|Finally, the optimized model was applied to business scenarios, successfully interpreting four categories of student groups with distinct behavioral characteristics  Through multi-dimensional centroid deviation analysis, it was discovered that the core elements driving student clustering were not absolute scores, but rather energy allocation and digital technology usage preferences. Based on these group personas, this paper proposes targeted academic diagnosis and pedagogical intervention strategies, constructing a complete closed-loop from underlying algorithmic optimization to top-level academic management. This study not only provides quantified data support for universities to implement personalized education but also offers a reliable technical paradigm for educational reform driven by big data.

55|Heading 2|1.1 研究背景与意义
56|Normal|研究背景：随着我国高等教育大众化进程的不断推进与教育信息化的深度普及，高校教务管理系统、在线学习平台以及校园网关中沉淀了海量的学生行为与学业数据。传统的教育评价体系长期依赖于期末考试成绩，这种单一的总结性评价虽然易于量化，但割裂了学习成果与学习过程的内在联系，无法透视学生分数背后的行为动因。面对日益复杂的学生群体，传统的评价方式难以精准识别学生的个体差异，进而导致教学管理的一刀切。因此，需引入先进的数据挖掘与机器学习技术，从海量数据中剥离出具有教育学价值的隐藏模式。
57|Normal|研究目的：本文旨在打破传统唯分数论的线性评价壁垒，将数据挖掘领域中成熟的聚类分析思想入学生学业与行为数据的多维评价体系中。通过对聚类算法的底层寻优机制进行改进与融合力求精准、稳定地识别出不同学生群体的行为特征与学业表现模式。最终目的不在于简单地将学生划分为优、良、中、差，而是旨在定位具有特定共性行为的学生群体而是深入剖析其知识薄弱环节，从而为教学管理人员提供量化的学业诊断依据，推动精准干预。
58|Normal|理论意义： 在算法理论层面，针对高维教育数据集极易使经典 K-Means 算法陷入局部最优的非凸优化难题，本研究深入探讨了基于概率论的 K-Means++ 初始化策略，并创新性地引入群体智能中的粒子群优化算法（PSO）。验证了融合算法在高维解空间中的全局寻优能力，丰富了聚类算法在教育数据挖掘领域的应用理论体系。
59|Normal|实践意义：本研究构建的数据预处理-特征重构-算法聚类-教务反馈闭环架构，能够将冰冷的数据转化为直观的群体画像。这不仅能帮助教师及时调整教学策略，实施因材施教的个性化教学方案，更能为学校教务部门构建科学、动态的教学质量评估体系提供直观的数据底座，最终切实提升高校的综合教学水平。
60|Heading 2|1.2 国内外研究现状
61|Normal|聚类分析作为无监督学习的核心技术，一直受到国内外学者的广泛关注，其在各个垂直领域的交叉融合也取得了丰硕成果。
62|Normal|算法优化机制研究现状：K-Means 算法因其逻辑清晰、时间复杂度极低而在业界广泛应用。然而，其对初始聚类中心极度敏感的先天缺陷一直是学术界攻克的重点。在国内研究中将 K-Means++ 模型成功应用于广电大数据中的电视节目分类分析中[1]，证明了该策略在复杂业务数据中的有效性；针对彩色图像分割场景，提出了 K-Means 算法的改良机制[2]。K-Means++ 算法通过轮盘赌式的概率分布策略，从数学上保证了初始聚类中心的相互排斥性，大幅降低了算法的盲目性。这些跨领域的应用实践为本研究将改进的聚类算法引入教育学领域提供了坚实的理论启发。
63|Normal|聚类算法与智能算法融合研究现状：近年来，为解决传统聚类算法基于梯度下降式搜索的局限性，将仿生群体智能优化算法引入聚类过程成为新的研究热点。系统性地探讨了 K-Means 与智能算法融合的可行性与演化路径[3]；粒子群智能算法（PSO）与 K-Means 融合的具体机制[4]，指出 PSO 强大的全局空间探索能力能够有效弥补 K-Means 的局部极值缺陷[4]。此外，将蚁狮优化算法（ALO）与 K-Means 结合[5]。此类融合算法的共性在于：利用群智能算法的前期发散性寻找全局近似最优解，再利用 K-Means 的局部收敛性进行精细微调，在聚类精度和稳定性上均展现出绝对优势。
64|Normal|聚类算法在教育数据挖掘中的应用现状与局限性分析：在教育数据挖掘（EDM）领域，虽然已有部分学者将数据挖掘技术（如朴素贝叶斯、关联规则等），引入教学分析[6]，但现有的学生成绩聚类研究仍存在显著局限[7][8][9][10][10]：多数研究的数据集特征单一[11][12]，仅仅围绕各科期末绝对成绩进行浅层聚类。这种做法忽略了学习是一项复杂的形成性评价过程，学生的学习动力、课外精力分配、考勤频次等非结构化行为变量被严重剥离。导致最终的聚类结果往往只能输出毫无业务指导价值的高分群与低分群，无法真正反馈给教学管理人员进行归因分析与干预。
65|Heading 2|1.3 本文主要研究内容
66|Normal|本文以独立的高维度学生学习行为与成绩数据集为研究对象，开展了一套完整的算法改进与应用闭环研究。首先，对原始数据进行清洗，并结合教育学先验知识提取衍生特征（如学习效率）；其次，深入剖析传统 K-Means 与 K-Means++ 的底层逻辑，进而引入粒子群优化（PSO）算法，构建出 PSO-KMeans 融合聚类模型；随后，基于肘部法与轮廓系数确定最佳聚类簇数，并在真实数据集上开展多算法的性能与稳定性对比实验；最后，将验证后的最优聚类模型应用于学生群体画像解译，生成具有针对性的学业诊断与教学干预策略。
67|Normal|评价维度的教育学重构： 突破了传统文献中单一依赖考试成绩的局限，本研究将重心转移至行为模式分析。通过特征交叉工程，创新性地构建了学业综合得分（期末与平时加权）与学习效率（成绩与学时比）等衍生维度，实现从单一总结性评价向多维形成性评价的转变。
68|Normal|寻优机制的底层跨域融合： 针对教育高维数据边界模糊、局部极值密集的特点，实现了 PSO 全局搜索与 K-Means 局部开发的深度融合。并通过严谨的多次重复实验，论证了 PSO-KMeans 算法在降低群体标准差与提升鲁棒性方面的决定性优势，从根本上解决了传统算法聚类结果不稳定的工程痛点。

80|Heading 2|2.1 聚类分析概述
81|Heading 3|2.1.1 聚类的基本思想与主要分类
82|Normal|聚类分析（Clustering Analysis）是无监督机器学习中的核心技术，其本质是根据物以类聚的原则，在没有先验标签的情况下，通过计算样本间的相似性，将物理或抽象对象的集合分组为多个由类似对象组成的簇。聚类的核心目标是最大化簇内的相似度，并最大化簇间的相异度。
83|Normal|在数据挖掘领域，常见的聚类算法可根据其基本逻辑分为以下几类：
84|Normal|划分式聚类（Partitioning Methods）：如 K-Means、K-Medoids。通过迭代将数据集划分为K个预定义的簇，适用于处理中小规模的球状分布数据集。
85|Normal|层次聚类（Hierarchical Methods）：如 AGNES、DIANA。通过自底向上或自顶向下的策略构建簇的层次结构，能够生成聚类谱系图，但计算复杂度较高。
86|Normal|基于密度的聚类（Density-based Methods）：如 DBSCAN。根据样本空间的密度分布进行聚类，能够识别任意形状的簇并有效过滤噪声点。
87|Normal|基于网格的聚类（Grid-based Methods）：如 STING。将数据空间划分为有限数量的网格单元，处理速度快，独立于样本数量。

98|Heading 2|2.2 算法选型依据
99|Normal|在明确了聚类分析的基本思想后，针对本文的教育数据挖掘任务，选用划分式聚类（尤其是 K-Means 算法框架）作为核心基座，主要基于以下三个维度的考量： 
100|Normal|(1)数据规模与计算复杂度适配： 本文的训练集包含 14,003 条多维样本记录。对于层次聚类（时间复杂度通常为或)或基于密度的 DBSCAN 算法而言，在如此规模的数据集上计算距离矩阵将产生庞大的内存与时间开销。而 K-Means 算法的时间复杂度近乎线性（，其中为样本数，为簇数，为迭代次数），能够保证在大规模教务数据上的极高运行效率。 
101|Normal|(2)数据空间分布拓扑吻合： 学生成绩与行为特征在经过缺失值填补与 Min-Max 归一化处理后，其在多维空间中通常呈现出相对密集的凸集或球状分布形态（见图 3-1 核密度分布图）。K-Means 通过最小化误差平方和（SSE），对这种球状分布的高维数据具有天然的极佳切分效果。

117|Heading 3|2.4.1 K-means++ 算法初始化策略
118|Normal|针对 K-Means 随机初始化导致的盲目性，K-Means++ 提出了基于概率分布的改进策略。其核心思想是：初始聚类中心之间的相互距离应尽可能远。 具体策略为：首先随机选择一个样本作为首个质心；随后计算每个样本到已选质心的最短距离；样本被选为下一个质心的概率与 成正比（即轮盘法选择）。这一改进显著提升了算法的收敛速度和稳定性。在本文研究中，K-Means++ 不仅作为评估最佳K值的基准工具，也是多算法对比中的重要参照。[17]

204|Normal|实验在的闭区间内对训练集进行了全量扫描。由图4-2可见：随着 值的增加，SSE 呈现必然的单调递减趋势。在值由 3 增加至 4 时，SSE 出现了 1291.87 的显著下降；而由 4 增加至 5 时，SSE 下降幅度衰减至 1280.76。尽管在此处肘部拐点的曲率变化不够锐利，但在引入轮廓系数作为惩罚项后发现，当时，模型的整体轮廓系数达到了 0.0894 的阶段性次优状态。结合教育管理中不宜将学生群体过度碎片化的先验原则，本研究锁定作为后续多算法对比的基准维度。

221|Normal|统计数据给出了决定性的证据：传统 K-Means 极度不稳定，其 10 次运行的 SSE 标准差高达 281.43； K-Means++ 虽然优化了初始点，但标准差依然达到了 284.09。这充分暴露了纯梯度下降算法的底层局限性：即使 K-Means++ 能够降低陷入劣质初始点的概率，但面对 18 维教育行为特征构建的复杂非凸空间，它依然缺乏跨越局部鞍点势垒的能力。相反，PSO-KMeans 通过粒子群的迭代搜索在全局寻找最优解，彻底摆脱了对初始点好坏的绝对依赖，从数学逻辑上规避了系统性的震荡缺陷。。
222|Normal|相比之下，PSO-KMeans 展现了断层式的稳定性优势：其 10 次独立运行的 SSE 均值达到了全局最低的 24387.51，且其标准差被大幅压缩至全场最低的 277.64。均值最低证明了其寻找全局最优解的能力最强，标准差最小证明了其受初始随机状态干扰的抗性最强。

553|Normal|//       被选中作为下一个聚类中心的概率越大（与 D²(x) 成正比）。
554|Normal|
555|Normal|void KMeans::initialize_centroids(const std::vector<DataRow>& data) {
556|Normal|    clusters.clear();
557|Normal|    clusters.resize(k);
558|Normal|    if (data.empty()) return;
559|Normal|
560|Normal|    // 第 1 个中心：在数据集中均匀随机抽取
561|Normal|    int idx = std::rand() % static_cast<int>(data.size());
562|Normal|    clusters[0].centroid = data[idx].features;
563|Normal|
564|Normal|    // 第 2..k 个中心：按 D²(x) 加权概率（轮盘赌）选取
565|Normal|    for (int i = 1; i < k; ++i) {
566|Normal|        std::vector<double> dist_sq(data.size());
567|Normal|        double total = 0.0;
568|Normal|
569|Normal|        // (a) 计算每个样本到「已选最近中心」的平方距离 D²(x)
570|Normal|        for (size_t j = 0; j < data.size(); ++j) {
571|Normal|            double min_d2 = std::numeric_limits<double>::max();
572|Normal|            for (int c = 0; c < i; ++c) {
573|Normal|                double d = distance(data[j].features, clusters[c].centroid);
574|Normal|                min_d2 = std::min(min_d2, d * d);
575|Normal|            }
576|Normal|            dist_sq[j] = min_d2;
577|Normal|            total += min_d2;
578|Normal|        }
579|Normal|
580|Normal|        // (b) 在 [0, total) 内生成随机阈值 r —— 概率 ∝ D²(x)
581|Normal|        double r = (static_cast<double>(std::rand()) / RAND_MAX) * total;
582|Normal|
583|Normal|        // (c) 累积分布查找：cumulative ≥ r 时落入对应样本
584|Normal|        double cum = 0.0;
585|Normal|        int sel = static_cast<int>(data.size()) - 1;
586|Normal|        for (size_t j = 0; j < data.size(); ++j) {
587|Normal|            cum += dist_sq[j];
588|Normal|            if (cum >= r) { sel = static_cast<int>(j); break; }
589|Normal|        }
590|Normal|
591|Normal|        // (d) 记为新中心
592|Normal|        clusters[i].centroid = data[sel].features;
593|Normal|    }
